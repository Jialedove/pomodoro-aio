# Pomodoro AIO

Pomodoro AIO 是一个 Obsidian 模块序列计时器。将任意数量的工作与休息模块排成列表，选择循环次数和模块结束后的衔接方式，然后按顺序执行。项目统计是可关闭的附加功能，不参与计时序列。

## 使用

- 每个工作模块有名称、时长、可选 Workspaces Plus 布局和黑屏设置；休息模块有名称、时长和黑屏设置。模块可新增、编辑、删除和拖动排序。
- macOS 桌面版的黑屏由原生助手覆盖鼠标所在显示器，显示当前模块名称和倒计时；Esc 或退出按钮只关闭黑屏，计时继续。助手不可用时退回 Obsidian 窗口遮罩；其他平台使用窗口遮罩。
- 侧栏沿用紧凑计时环与任务行；工作模块的事情输入框可选择当日日记里未勾选的待办，并可在该行清空或完成事情。刷新按钮会重新读取日记候选。
- 双击某行的“工作”或“休息”可把它选为当前模块，再按“开始序列”。等待开始下一段时也可改选；正在计时的段需先完成或重置，避免丢失已产生的工作时长。
- 可以无限循环、执行一次，或指定完整循环次数；模块结束后可以等待确认，也可以自动开始下一项。
- 执行界面显示当前模块、倒计时、下一项和工作/休息/完整循环计数。展开序列后仍可编辑定义；正在运行的模块使用开始时保存的快照。
- “完成本段”结算当前已产生的有效工作时长并推进序列，不代表事情完成。“完成事情”先结算正在运行的工作，再勾选日记待办并清空该工作模块的任务选择。
- 自然完成的工作按计划分钟数除以 25 折算番茄；手动完成按实际有效分钟数折算。非零时长最低记 `0.1🍅`，零时长和休息不记番茄。
- 开启“推进中的项目”后，只在独立项目页关联或解除工作、查看项目累计番茄并打开项目笔记。一个工作最多关联一个项目；关闭后计时和日记结算照常运行。

## 数据与可靠性

设置保存在插件 `data.json`，运行态保存在 Obsidian local storage 的 `pomodoro-aio-runtime`。每段开始都会保存模块 ID、名称、时长、黑屏、工作区和当时解析出的项目关系。暂停和重载恢复使用绝对时间；工作结算使用持久化 journal、日记原子修改、幂等重试与项目失败队列。项目写入失败不会撤销已完成的日记结算。

首次读取旧设置时，普通专注转换为工作与休息模块，A/B 循环转换为线性工作模块；旧“每 N 轮休息”展开为序列末尾的休息模块。旧长专注时长成为普通工作模块。旧运行态与未完成 journal 会先通过兼容恢复路径处理，新的启动和推进只走模块序列。

完整重构目标和验收记录见 [目标书](docs/refactor-target-v1.md)与[重构上下文](docs/refactor-context.md)。

## 开发与验证

只编辑 `src/main.js` 及其模块。根目录 `main.js` 是 esbuild 产物，不要直接编辑。

```bash
npm ci
npm run check
```

`npm run check` 执行类型检查、lint、单元/集成测试、生产构建和产物一致性检查，并在 macOS 上编译原生黑屏助手。真实 Obsidian 回归步骤见 [手动清单](docs/manual-regression.md)。

## 安装到本地 Obsidian 库

```bash
npm run install:vault
```

此命令覆盖插件目录中的 `main.js`、`manifest.json`、`styles.css`，在 macOS 上另复制 `bin/pomodoro-blackout`；保留 `data.json`。安装后需重载插件。默认目标是 Dove 的卡片库；可通过 `OBSIDIAN_PLUGIN_DIR` 临时指定其他插件目录。
